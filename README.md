# 🔮 Customer Churn Prediction Pro

This project predicts customer churn using a robust Machine Learning pipeline. The goal is to identify customers at high risk of leaving, enabling proactive retention strategies.

## 🚀 Features & ML Methodology

This project goes beyond simple accuracy to evaluate model performance realistically for an imbalanced target variable (Churn). 
- **Robust Pipeline:** End-to-end scikit-learn `Pipeline` handling Missing Values, Outlier Capping (IQR), Log Transformations (Skewness), Encoding (OneHot & Ordinal), and Feature Scaling (StandardScaler).
- **No Data Leakage:** All data preprocessing steps (imputation, capping, scaling) are strictly fitted on the training data only, and transformed onto the test data.
- **Experimentation Phase:** Multiple models were evaluated in the original notebook, including Logistic Regression, KNN, SVM, tree-based models, Random Forest, and XGBoost. SMOTE was explored during this experimentation phase to address class imbalance.
- **Final Production Model:** XGBoost achieved the best overall performance during model comparison, so it was selected as the final model for `train_model.py` and the Streamlit application.
- **Handling Imbalanced Data in Production:** The final XGBoost pipeline uses `scale_pos_weight` tuning instead of SMOTE, taking advantage of XGBoost's native imbalance handling.
- **Evaluation Metrics:** Optimized and evaluated for **F1-score**, Precision, Recall, and ROC-AUC, moving past misleading accuracy metrics on imbalanced data.

## 📁 Project Structure

- `Customer_Churn_Prediction_3.ipynb` - The original interactive exploratory data analysis (EDA), model comparison, and experimentation notebook.
- `train_model.py` - The robust final XGBoost training script that properly handles the data split and pipeline to prevent leakage, producing the production pipeline.
- `app.py` - The user-facing Streamlit dashboard for real-time predictions.
- `churn_artifacts.pkl` - The serialized end-to-end model artifacts generated by the training script.
- `requirements.txt` - Project dependencies.

## ⚙️ Setup & Installation

1. **Clone the repository** (or download the directory).
2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Train the robust model** (Generates `churn_artifacts.pkl`):
   ```bash
   python train_model.py
   ```
4. **Run the Streamlit Dashboard:**
   ```bash
   streamlit run app.py
   ```

## 📊 Deployment

The Streamlit dashboard provides a premium, user-friendly UI to input demographic, financial, and service information. It displays not only the prediction (Churn / No Churn) but also the exact probability, offering clear insights for business action.

## 💡 Limitations & Future Improvements

- **Current Limitations:** The data is synthetic and collected at a single snapshot in time. A time-series approach mapping customer behavior longitudinally could capture churn triggers more accurately.
- **Future Improvements:** Integrate an API (Flask/FastAPI) alongside the Streamlit app to serve predictions to other backend microservices, enabling automated retention emails.
